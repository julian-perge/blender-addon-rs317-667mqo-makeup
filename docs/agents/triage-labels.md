# Triage labels

Local issues record one of these role strings in their `Status:` line, or `resolved` once the ticket is closed ([Issue tracker](issue-tracker.md)).

| Role | Status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on the reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an unattended agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill names a triage role, use the corresponding status above.
