# Item slots and covers come from the wear positions of cache 2757

Snapshot 430 holds no item wear positions, so the appearance panel first used a 2021 osrsbox slot list, a rule that guessed which torso items bring their own arms, and a table of the OSRS Wiki's platebodies. On 2026-11-07 the owner chose to replace those guesses with the wear positions of OpenRS2 cache 2757 (build 242, 2026-11-03), the newest Old School cache ([research](../research/cache-2757-wear-positions.md)).

`data/item_wear.json` holds, for the 3,058 snapshot 430 items with a worn model (counted 2026-11-07), the slot (`wearPos1`) and the slots hidden (`wearPos2`, `wearPos3`), by item id, with a status saying whether the name or worn model ids changed since snapshot 430. `scripts/generate-item-wear.py` writes it and records both caches' SHA-256. Picking an item sets Covers arms, Covers hair, Covers jaw, Covers hands and Covers shield from the slots it hides. A toggle the item hides is locked while ticked, unless the item's worn models changed since snapshot 430: then the toggle is free and the panel says "Remodelled since 2017: check covers" (553 items). Whether each item hid the same slots in July 2017 is not verified.
